# Personal Portfolio Website

Welcome to my **Personal Portfolio Website**! 🌐

This project is a simple and responsive portfolio website created using **HTML and CSS**. It is designed to showcase my profile, skills, projects, education, and other professional information in a clean and user-friendly layout.

## 🚀 Features

* Responsive portfolio design
* Personal introduction section
* Skills and technologies section
* Projects showcase
* Education and experience information
* Profile image
* Clean and simple UI
* Custom CSS styling
* Easy to customize

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📂 Project Structure

```text
personal-portfolio-website/

├── image/

│
├── portfolio/

```

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/yourusername/personal-portfolio-website.git
```

2. Open the project folder.

3. Open:

```text
portfolio/home.html
```

4. You can also use **VS Code + Live Server** to run the website.

## 🎨 Customization

You can easily customize the portfolio by editing:

* `home.html` — website content and structure
* `style.css` — colors, fonts, layout, and styling
* `girl.jpeg` — profile image
